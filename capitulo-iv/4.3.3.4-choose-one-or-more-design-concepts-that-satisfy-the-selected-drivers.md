### **4.3.3.4 Choose One or More Design Concepts That Satisfy the Selected Drivers** {#4.3.3.4-choose-one-or-more-design-concepts-that-satisfy-the-selected-drivers}

Para satisfacer los drivers definidos, se seleccionan los siguientes patrones, estilos y tácticas de arquitectura:

1. **Táctica: Autenticación de Usuarios (*Authenticate Users*)**  
   * **Identity Provider Centralizado (Keycloak):** Implementación de un servidor IdP dedicado para gestionar la federación de identidades, almacenamiento de credenciales hash (Argon2 / BCrypt) y emisión de tokens OIDC.  
   * **Validación Descentralizada de Tokens (*Stateless JWT Verification*):** Los microservicios y el API Gateway no consultan la base de datos de usuarios para cada petición; en su lugar, verifican la firma criptográfica del JWT utilizando la clave pública expuesta por el IdP vía un punto final **JWKS** (*JSON Web Key Set*) en caché local.  
2. **Táctica: Autorización de Usuarios (*Authorize Users*)**  
   * **Modelo Híbrido RBAC \+ ABAC:**  
     * **RBAC (Role-Based Access Control):** Define roles de alto nivel (ROLE\_MECHANIC, ROLE\_WORKSHOP\_ADMIN, ROLE\_FLEET\_MANAGER, ROLE\_SYSTEM\_ADMIN).  
     * **ABAC (Attribute-Based Access Control):** Valida atributos contextuales dinámicos como tenant\_id \== resource.tenant\_id, workshop\_location, y device\_trust\_level.  
3. **Táctica: Aislamiento de Datos y Resistencia a Ataques (*Isolate Data & Resist Attacks*)**  
   * **Propagación de Contexto Seguro (*Gateway Token Exchange & Header Ingestion*):** El API Gateway remueve cualquier encabezado X-Tenant-ID proveniente del exterior, valida el JWT firmado, extrae el tenant\_id oficial del payload del token e inyecta un encabezado interno sanitizado X-Scope-Tenant-ID hacia la red privada de microservicios.  
   * **Patrón Multi-Tenant *Discriminator Column* con PostgreSQL RLS:** Cada tabla de negocio contiene la columna tenant\_id. Se aplican políticas de **Row-Level Security (RLS)** de PostgreSQL, donde la sesión SQL ejecuta SET LOCAL app.current\_tenant \= 'tenant\_xyz', impidiendo a nivel de motor de BD la lectura de registros ajenos.
