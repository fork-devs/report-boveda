#### ***4.3.2.3 Choose One or More Elements of the System to Refine*** {#4.3.2.3-choose-one-or-more-elements-of-the-system-to-refine}

En esta iteración se seleccionan los componentes de transporte, ingesta y comunicación distribuida de la plataforma:

| Bounded Context / Componente | Responsabilidad Refinada |
| ----- | ----- |
| IoT Ingestion Service | Servicio especializado en recibir streams de datos telemáticos desde dispositivos OBD-II vía protocolos ligeros (HTTP/REST y WebSockets), validar payloads y publicarlos inmediatamente en el bus de eventos. |
| IoT Telemetry Processor | Consumidor asíncrono que procesa eventos telemáticos, calcula métricas de diagnóstico, evalúa códigos DTC y persiste el historial en la base de datos TimescaleDB. |
| Event Broker (Apache Kafka) | Plataforma de event streaming que actúa como búfer distribuido de alta capacidad, desacoplando la ingesta del procesamiento de órdenes y analítica. |
| Billing & Work Order Outbox Engines | Mecanismos locales de persistencia de eventos (Transactional Outbox) integrados en las bases de datos PostgreSQL para garantizar la publicación atómica de eventos de dominio. |
