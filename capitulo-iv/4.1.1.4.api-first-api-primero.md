#### ***4.1.1.4. API First (API primero)*** {#4.1.1.4.-api-first-(api-primero)}

Diseñaremos los contratos de las interfaces antes de programar la lógica interna.

**Qué significa:** primero escribimos cómo se hablará con el sistema (Interfaz de Programación de Aplicaciones, Application Programming Interface, API: rutas REST documentadas en OpenAPI y/o servicios gRPC con Búferes de Protocolo, Protocol Buffers, proto), con ejemplos, errores y versiones. Recién después lo implementamos.

**Cómo lo usaremos:** cada capacidad (registrar vehículo, crear orden, reservar repuesto, emitir comprobante, enviar telemetría) tendrá su contrato versionado, con errores tipados y con identificador de taller obligatorio. Esto facilitará integrar la app móvil del mecánico, el GPS/OBD-II y pasarelas como Stripe sin adivinar formatos. Un cambio incompatible solo podrá ir en versión mayor (v2).
