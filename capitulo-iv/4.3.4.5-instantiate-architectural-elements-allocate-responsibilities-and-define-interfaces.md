### **4.3.4.5 Instantiate Architectural Elements, Allocate Responsibilities, and Define Interfaces**  {#4.3.4.5-instantiate-architectural-elements,-allocate-responsibilities,-and-define-interfaces}

| Componente Arquitectónico | Capa / Ubicación | Responsabilidades Principales |
| :---- | :---- | :---- |
| **OpenTelemetry Agent / SDK** | Runtime de Microservicios | Intercepta peticiones HTTP/gRPC, queries SQL y mensajes Kafka; genera spans y propagadores W3C; expone datos de telemetría al Collector. |
| **OpenTelemetry Collector Cluster** | Capa de Infraestructura de Telemetría | Recibe, procesa, filtra y transforma métricas, logs y trazas. Aplica políticas de *Tail-Based Sampling* y enruta datos hacia Jaeger, Prometheus y Loki. |
| **Jaeger / Grafana Tempo** | Almacenamiento y Visualización de Trazas | Almacena árboles de trazas distribuidas, calcula gráficos de dependencias entre microservicios y permite el análisis de latencia crítica (*Waterfall View*). |
| **Prometheus & Alertmanager** | Motor de Métricas y Alertas | Realiza *scraping* de métricas cada $15s$, evalúa reglas de alerta configuradas (PromQL) y despacha notificaciones vía PagerDuty/Slack. |
| **Grafana Dashboard System** | Capa de Presentación de Operaciones | Paneles de control unificados para la visualización de las métricas clave de salud del sistema (Latencia, Tráfico, Errores y Saturación \- *The 4 Golden Signals*). |
| **Resilience4j Circuit Breaker Module** | Capa de Aplicación / Dominio | Protege las invocaciones entre microservicios y APIs externas, abriendo el circuito ante tasas de error configuradas y ejecutando respuestas de *Fallback*. |
| **Loki Log Collector** | Agregador de Registros | Indexa etiquetas metadata de registros estructurados JSON y permite consultas de texto de alta eficiencia asociadas al trace\_id. |
