### **4.3.3.5 Instantiate Architectural Elements, Allocate Responsibilities, and Define Interfaces**  {#4.3.3.5-instantiate-architectural-elements,-allocate-responsibilities,-and-define-interfaces}

| Componente Arquitectónico | Capa / Ubicación | Responsabilidades Principales |
| :---- | :---- | :---- |
| **Keycloak Identity Provider (IdP)** | Infraestructura de Identidad | Servidor OIDC/OAuth2 encargado del registro de usuarios, autenticación primaria (MFA), emisor de JWTs y publicación de claves públicas JWKS. |
| **API Gateway Security Filter** | Borde (*Edge*) | Valida el token JWT enviado por el cliente (firma RS256 y vigencia). Bloquea peticiones no autenticadas, aplica *Rate Limiting* por inquilino y reenvía encabezados de contexto de identidad hacia la red interna. |
| **Tenant Context Interceptor (SDK)** | Microservicios (Filtro HTTP/gRPC) | Middleware embebido en cada microservicio que intercepta el encabezado X-Scope-Tenant-ID, parsea el contexto del usuario y lo registra en un objeto TenantContext dentro del hilo de ejecución actual (ThreadLocal). |
| **Authorization Enforcement Point (AEP)** | Microservicios (Capa de Aplicación) | Evalúa los permisos granulares (RBAC/ABAC) comparando los roles del usuario del JWT con los atributos del dominio antes de ejecutar cualquier método o caso de uso. |
| **Tenant-Aware Repository Adapter** | Capa de Persistencia | Componente de datos que configura la variable de sesión de la base de datos (SET LOCAL app.current\_tenant) antes de ejecutar consultas JPA/SQL, activando las reglas RLS. |
| **PostgreSQL DB with Row-Level Security** | Base de Datos | Motor relacional configurado con políticas RLS que garantizan el filtrado automático e inquebrantable de filas por tenant\_id. |
