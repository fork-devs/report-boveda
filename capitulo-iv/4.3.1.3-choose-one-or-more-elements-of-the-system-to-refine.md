### **4.3.1.3 Choose One or More Elements of the System to Refine**

El elemento seleccionado para su refinamiento en esta iteración es el sistema global DriveOS en su totalidad, transformándolo desde una noción abstracta de software hacia una estructura de subsistemas desacoplados por Bounded Contexts según los principios de Domain-Driven Design (DDD).

| Bounded Context | Responsabilidad |
| :---- | :---- |
| Workshop Management Context | Gestión de talleres, sucursales y configuración del tenant. |
| Fleet Management Context | Gestión de vehículos y clientes asociados. |
| Work Order Context | Gestión del ciclo operativo mediante órdenes de trabajo. |
| Inventory Context | Control de repuestos y disponibilidad. |
| Telemetry Context | Procesamiento de información proveniente de dispositivos IoT. |
| Billing Context | Facturación e integraciones tributarias. |
