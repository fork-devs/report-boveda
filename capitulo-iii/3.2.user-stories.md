## ***3.2. User Stories***

Las Epics agrupan las capacidades que materializan las hipótesis del producto. Las User Stories siguen la estructura Como \[rol\], deseo \[funcionalidad\], para \[beneficio\]. Para sus criterios de aceptación se emplea un estilo orientado a reglas, con condiciones observables que permiten comprobar si la historia puede considerarse terminada.
