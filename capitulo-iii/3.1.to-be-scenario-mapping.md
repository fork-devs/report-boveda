## ***3.1. To-Be Scenario Mapping***

Para estructurar los escenarios futuros se revisaron las tareas, dificultades y expectativas registradas para cada segmento. Primero se separaron las actividades del gestor y del técnico. Después se agruparon las acciones relacionadas, se ordenaron como fases y se contrastaron con el proceso actual basado en cuadernos, fotografías dispersas, uso separado del escáner y conectividad inestable. La revisión permitió identificar qué acciones cambian con DriveOS Workshop y cómo ese cambio modifica lo que cada persona piensa y siente durante el servicio.
