### ***5.2.3 Source Code Style Guide & Conventions*** {#5.2.3-source-code-style-guide-&-conventions}

Para mantener la legibilidad y calidad del código entre los desarrolladores, se adoptaron guías de estilo internacionales respetando la nomenclatura en inglés en todas las capas del software:

**• Google Java Style Guide:**  Aplicada en todos los microservicios Java (Spring Boot 4 y Java 21). Establece nombres de clases en PascalCase ('WorkOrdersController'), métodos en camelCase ('calculateNetMargin'), constantes en UPPER\_SNAKE\_CASE ('MAX\_FAILED\_ATTEMPTS'), indentación de 4 espacios y uso estricto de anotaciones de validación (Bean Validation) en DTOs.

**• Google TypeScript Style Guide:**  Aplicada en la aplicación web Angular 21 ('driveos-web'). Define componentes modulares, servicios desacoplados con RxJS, tipado estricto en TypeScript sin uso de 'any' y formateo automático con Prettier.

**• Gherkin Style Conventions:**  Aplicada en la redacción de especificaciones de pruebas de aceptación BDD (.feature), asegurando escenarios declarativos y centrados en el lenguaje ubicuo del taller.
