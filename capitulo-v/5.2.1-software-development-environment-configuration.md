### ***5.2.1 Software Development Environment Configuration*** {#5.2.1-software-development-environment-configuration}

Para garantizar un entorno de trabajo homogéneo entre los cinco integrantes del equipo y eliminar discrepancias entre entornos locales y de integración, se estandarizó el conjunto de herramientas categorizadas por actividad de ingeniería, respetando las restricciones técnicas establecidas en el Statement del proyecto:

| Categoría de Actividad | Herramienta Seleccionada | Versión Oficial | Ruta de Referencia / Acceso (SaaS o Descarga) | Propósito en el Proyecto |
| ----- | ----- | ----- | ----- | ----- |
| Project Management | Trello | Cloud SaaS | https\://trello.com/b/tY4tq1RU/driveos-workshop-architectural-design-backlog | Gestión ágil del Product Backlog, tableros Kanban de iteraciones ADD y Sprint Backlog. |
| Requirements & UX | UXPressia / Miro | Cloud SaaS | https\://uxpressia.com / https\://miro.com | Elaboración colaborativa de User Personas, Empathy Maps, Journey Maps e Impact Maps. |
| Software Modeling | Structurizr DSL / Lucidchart | CLI 1.35 / SaaS | https\://structurizr.com / https\://lucid.app | Modelado de vistas C4 (Contexto, Contenedores, Componentes, Despliegue) y diagramas UML. |
| Database Design | dbdiagram.io / Vertabelo | Cloud SaaS | https\://dbdiagram.io / https\://vertabelo.com | Diseño y normalización de esquemas relacionales PostgreSQL y series temporales TimescaleDB. |
| Backend Development (Java) | IntelliJ IDEA / Eclipse | OpenJDK 21 (LTS) | https\://adoptium.net/temurin/releases/?version=21 | Desarrollo de los microservicios core transaccionales con Spring Boot 3.2+. |
| Backend Development (Go) | Visual Studio Code | Go 1.22.x | https\://go.dev/dl/ | Desarrollo del API Gateway perimetral y microservicio de ingesta IoT de alta velocidad. |
| Analytics & IoT Engine | PyCharm / VS Code | Python 3.11.x | https\://www\.python.org/downloads/ | Desarrollo del motor de evaluación de reglas telemétricas y diagnósticos predictivos. |
| Software Testing | JUnit 5 / Testcontainers | 5.10.x / 1.19.x | https\://junit.org / https\://testcontainers.com | Pruebas unitarias de dominio y pruebas de integración con PostgreSQL, Kafka y Redis efímeros. |
| BDD Testing Suite | Cucumber / Gherkin | 7.15.x | https\://cucumber.io/docs/gherkin/ | Especificación ejecutable de pruebas de aceptación en archivos .feature en lenguaje ubicuo. |
| API Testing & Execution | Postman | Desktop v10.x | https\://www\.postman.com/downloads/ | Ejecución de colecciones de pruebas, inspección de cabeceras JWT y validación de endpoints. |
